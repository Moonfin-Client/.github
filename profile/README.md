## About Moonfin

Moonfin is a collection of premium Jellyfin and Emby client applications. We focus on refined user experiences, improved UI/UX, and platform-specific optimizations while keeping full compatibility with Jellyfin and Emby servers, so your media library is more accessible and enjoyable on every device.

## What Makes Moonfin Different

- **Modern UI**: Refined layouts, better information density, and smoother animations
- **Emby support**: Every native client connects to Jellyfin 10.8.0+ or Emby 4.8.0.0+ from one unified app
- **First-class Seerr**: The first native Jellyfin clients with Seerr discovery and requesting
- **A companion server plugin**: Moonbase hosts the standalone Moonfin web app, syncs settings across clients, and proxies Seerr, MDBList, and TMDB
- **Platform-optimized**: Each client is tailored for its device, from remote-first TV layouts to touch and desktop
- **Open source**: All improvements are available for the community to use and contribute to

Shared highlights across clients include a cross-server unified library, a profile-aware featured media bar, plugin-backed settings sync and MDBList ratings, in-player trailer previews, subtitle downloads, Live TV & DVR, playlist management, global search, and automatic updates. Each client's repo lists its full feature set.

## Projects

| Project | What it is |
|---|---|
| **[Moonbase Plugin](https://github.com/Moonfin-Client/Plugin)** | The Jellyfin/Emby server plugin that powers the ecosystem: settings sync, Seerr proxy and SSO, shared MDBList/TMDB APIs, custom themes, and the hosted Moonfin web app. Strongly recommended for all users, and required for Seerr. |
| **[Moonfin Core](https://github.com/Moonfin-Client/Moonfin-Core)** ([wiki](https://github.com/Moonfin-Client/Moonfin-Core/wiki)) | The unified Flutter client for Android, iOS, macOS, Windows, Linux, web, and experimental Tizen, and the shared codebase behind the Android TV and Apple TV apps. |
| **[Smart TV](https://github.com/Moonfin-Client/Smart-TV)** ([wiki](https://github.com/Moonfin-Client/Smart-TV/wiki)) | The Samsung (Tizen) and LG (webOS) client, built with React/Enact/Sandstone over native per-platform video pipelines. |
| **[Roku](https://github.com/Moonfin-Client/Roku)** ([wiki](https://github.com/Moonfin-Client/Roku/wiki)) | The Roku client, built in BrighterScript and forked from the official Jellyfin Roku app. |

For features, codec support, install steps, and build instructions, see each project's README and wiki.

## Installation & Setup

Each client has its own install method, linked in the table above:

- **Android / Fire TV**: [Google Play](https://play.google.com/store/apps/details?id=org.moonfin.androidtv), or sideload the APK from releases (Android 6.0+)
- **iOS / tvOS / macOS**: [App Store](https://apps.apple.com/app/moonfin/id6761283970), or sideload via TestFlight
- **Windows / Linux**: Installers and binaries in [Moonfin-Core releases](https://github.com/Moonfin-Client/Moonfin-Core/releases); Linux is also on the AUR (`yay -S moonfin`)
- **Samsung (Tizen) / LG (webOS)**: Sideload the WGT/IPK from [Smart-TV releases](https://github.com/Moonfin-Client/Smart-TV/releases)
- **Roku**: Install from the [Roku Channel Store](https://channelstore.roku.com/details/92a83c9f4112b76a7bcee3dc076254ca:3251a91bf7af7339652d5409ccfdcb39/moonfin), or sideload the ZIP from [releases](https://github.com/Moonfin-Client/Roku/releases) via developer mode
- **Web**: Install the [Moonbase Plugin](https://github.com/Moonfin-Client/Plugin) on your server; it serves the standalone Moonfin web app as an installable PWA at `/Moonfin/Web/`

### Optional: Seerr

Install [Seerr](https://seerr.dev/) on your network, then set its URL in the Moonbase plugin settings (Jellyfin Dashboard, Plugins, Moonfin). The plugin proxies all Seerr traffic through Jellyfin, so clients only need to reach your server.
